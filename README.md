# Dental Care Selector — Premium Edition 🦷

Автономный HTML-инструмент для персонального подбора средств гигиены полости рта.  
Четыре режима: Экспресс, Базовый, Профессиональный, Премиум («всё за меня»).  

**Особенности**  
- Полностью офлайн (один HTML-файл)  
- Данные не покидают браузер  
- Сохранение результатов в localStorage (с согласия)  
- Генерация резюме, списка средств и промпта для ИИ  
- Адаптивный интерфейс  

**Как использовать**  
1. Откройте `dental-care-selector.html` в любом браузере  
2. Выберите режим и ответьте на вопросы (или нажмите «Премиум»)  
3. Получите персональные рекомендации
